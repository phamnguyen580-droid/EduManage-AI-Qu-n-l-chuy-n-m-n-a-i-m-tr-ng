# EduManage AI V3

Ứng dụng web quản lý chuyên môn đa điểm trường (một file HTML, không cần cài đặt hay máy chủ).

## Chạy thử
Mở file `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `edumanage-ai`), tải toàn bộ nội dung thư mục này lên (`Add file` → `Upload files`).
2. Vào **Settings → Pages**.
3. Tại **Build and deployment**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)` → **Save**.
4. Sau 1–2 phút, trang chạy tại `https://<tên-tài-khoản>.github.io/edumanage-ai/`.

## Lưu ý
- Dữ liệu được lưu trong `localStorage` của trình duyệt, riêng từng thiết bị/trình duyệt và không đồng bộ giữa các máy.
- Ứng dụng tải phông chữ Be Vietnam Pro từ Google Fonts; nếu không có mạng sẽ dùng phông hệ thống.
